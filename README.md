# UniVerse - Integrated Academic Management System

A comprehensive student management platform with AI-powered study tools, certificate vault, and smart campus features.

## 🚀 Quick Start

### Backend
```bash
cd backend
npm install
npm run dev
```

### Frontend
```bash
cd frontend
npm install
npm run dev
```

### Database Setup
```bash
cd backend
npx prisma migrate dev
npx prisma studio
```

## 🎯 Key Features

- **Certificate Vault**: Secure digital certificate storage and management
- **AI Study Tools**: Smart note generation and content summarization
- **Academic Management**: Course enrollment, exam scheduling, hall tickets
- **Student Portfolio**: Comprehensive digital portfolio with achievements
- **Club Management**: Event planning and club administration
- **Security Features**: QR-based verification and fraud detection

## 🛠️ Tech Stack

- **Backend**: Node.js, Express, PostgreSQL, Prisma
- **Frontend**: React, TypeScript, Tailwind CSS
- **Security**: JWT authentication, QR codes, file validation
- **AI**: Content processing and intelligent summarization

## 🌐 Access Points

- **Frontend**: http://localhost:3000
- **Backend API**: http://localhost:3001/api
- **Database Studio**: http://localhost:5556
